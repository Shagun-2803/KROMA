# KROMA Studio: Portfolio Website

A responsive, mobile-first website for a fictional design studio, built with plain HTML, CSS and JavaScript. No frameworks.

## Features
- Mobile-first responsive layout (Flexbox and Grid, breakpoints at 640 / 768 / 1024px)
- Sticky header, hamburger menu and scroll-spy navigation
- Scroll-reveal animations with IntersectionObserver
- Filterable work grid
- Contact form with JavaScript validation and accessible error messages
- Respects `prefers-reduced-motion`
